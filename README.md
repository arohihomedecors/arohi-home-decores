# Arohi Home Decore — starter catalogue website

A lightweight bilingual (English/Hindi), mobile-friendly product catalogue with WhatsApp order-message links and a UPI information section. It does **not** collect card details or process payments itself.

## Files

- `index.html` — page structure and homepage copy
- `styles.css` — responsive styling
- `products.js` — business settings and editable product catalogue
- `script.js` — English/Hindi toggle, product rendering and WhatsApp messages
- `images/` — put your own product photos here

## Before publishing

1. Open `products.js`.
2. Set `whatsappNumber` to your business WhatsApp number using digits only and the country code. Example format only: `91XXXXXXXXXX`. Do not include `+`, spaces or hyphens.
3. Set `upiId` only after you verify the exact UPI ID you intend to publish. The site currently displays this as contact information; it does not create a UPI payment or verify payments.
4. Update all product names, descriptions and sample prices. The current amounts are examples, not market-price advice.
5. Add your own product photographs to `images/` using these exact filenames:
   - `toran.jpg`
   - `floral-strings.jpg`
   - `wall-hanging.jpg`
   - `flower-arrangement.jpg`
   If you choose other filenames, update the matching `image` field in `products.js`.
6. Add your actual delivery, cancellation, return and contact details before launch. Avoid promising shipping times until you can meet them.
7. Test on a phone, including the language switch and WhatsApp order button.

## Publish free with GitHub Pages

1. Create or sign in to a GitHub account.
2. Create a **public** repository, for example `arohi-home-decore-site`. GitHub Pages for a public repository on GitHub Free is a common no-cost static-hosting option; check GitHub's current plan/Pages limits before relying on it.
3. Upload `index.html`, `styles.css`, `products.js`, `script.js`, `README.md`, and the `images` folder. Keep the folder structure intact.
4. In the repository, open **Settings → Pages**.
5. Under the build/deployment source, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for the Pages deployment to finish. GitHub will show the published URL in Settings → Pages. Use that exact URL; do not guess the URL.
7. Open the published URL on a mobile phone and test all content and links.
8. To make edits, update the relevant file in the repository. GitHub Pages redeploys after the change is pushed.

## Privacy and safety notes

- Do not put customer phone numbers, addresses, order records, passwords or private keys into this public repository.
- The WhatsApp number and UPI ID are intentionally blank. Do not publish until you have added and checked your own business details.
- The product images are placeholders generated by the page when image files are missing. Add real product photographs before launch.
- A WhatsApp link opens a chat; it does not send a message automatically. The customer still reviews and sends the message.
- The website does not verify whether a UPI transfer has arrived. Check your own bank/payment app before confirming payment or dispatch.
- For UPI, share your verified UPI ID/QR securely with customers after confirming the order. Do not ask customers to share their UPI PIN or OTP.
- This is a static website and has no admin dashboard, inventory management, checkout, payment gateway, order database or automated shipping integration.
